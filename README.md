# Project-1-Cupcake-Collector

My project submission for the cupcake collector game. 

The source code is the "main.py" file. 

For this game you play as claude, you are an AI and AIs need tokens to work. So the more you do move around the more tokens you end up using. If you use up all your movement tokens before collecting all the coins you loose. When you collect a coin, your movement tokens increase so you can move more. This makes falling down and making mistakes punishable. Collect all 5 coins to win. You use your arrow keys to move and can see your highest movement token score at the end. Press "r" to reset when you win or loose. 

Play here: https://karimr4.github.io/Project-1-Cupcake-Collector/
